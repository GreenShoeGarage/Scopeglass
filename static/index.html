Scope and assumptions

Allowed networks: loading…

Connections originate from the computer running Scopeglass. Reachable here does not establish public internet exposure. VPNs, containers, and firewall rules can change what it sees. No matches does not establish that a device is absent.

A verified protocol badge means a recognizable response was observed. Device type can still be uncertain. Port hints are unverified. TLS certificate trust is not evaluated. Severity describes review priority; confidence describes the strength of the identification evidence.

Search help and saved views

Combine terms with spaces (AND), quote phrases, and prefix a term with − to exclude it (use the keyboard hyphen). Search reads the selected scan; it never starts one.

Filters: ip: / net: (IPv4 or CIDR), port: (number or range), service:, protocol: (verified only), type:camera|streaming|unknown, tag:, name:, expected:true|false, verified:true|false, severity:, age:>7d. Use text:"http://" for literal colon text. A plain service hint is unverified; type:camera uses likely camera metadata.

Views save filters, sort order, layout, and the selected scan. “Latest scan” stays live; a numbered scan stays pinned. Changing the name creates a copy.

Create a schedule from the selected completed scan. It repeats all of that scan’s hosts and ports, regardless of your search filters. New schedules are enabled; the first run is after the interval.

60 = hourly · 1,440 = daily · 10,080 = weekly. The server must remain running; your browser can be closed.

Only one scan runs at a time. Due schedules wait for the scanner. After downtime, one overdue run is performed; missed intervals are not replayed. Pausing or deleting a schedule does not stop an already running scan.

Access & setup

Local access is ready. To add a login or configure an HTTPS address, stop the server and run the guided setup:

python3 server.py --config config.json --setup

Use your installation’s configuration path. The ZIP includes Docker, Linux service, and HTTPS proxy examples in the deploy folder.

Change administrator passphrase

Use 15–128 characters. A few unrelated words make a useful passphrase. Saving revokes other browser sessions and keeps this browser signed in.

Signing out hides this workspace. Scheduled assessments continue on the server.

Save / Recover

Manage your data

Reading saved data…

Restore replaces the server’s assessment data; the login account stays unchanged. Imported schedules stay paused and unfinished scans become interrupted. Browser drafts from this installation are cleared in this browser after restore; download unsaved edits first.

Keeps the latest scan and all scans needed by baselines, pinned views, schedules, change evidence, and their reference chains. Names, notes, saved views, and reviewed changes remain. This is a manual cleanup, not automatic deletion.

Fresh Start removes all scans, observations, baselines, device annotations, saved views, schedules, and change reviews from this server. It also clears Scopeglass settings and drafts in this browser. Your server configuration, login account, and existing backup files remain.

Before applying any change, Scopeglass saves a checked SQLite backup beside the database, in its backups folder. Preview expires after 10 minutes and must be repeated if data changes. Stop or finish active scans first.
